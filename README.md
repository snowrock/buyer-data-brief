# SnowRock Buyer Data Brief Builder

A free browser tool for AI teams preparing to license company data. Describe a task, the records it needs, permission questions, a sample decision, delivery and separate budgets. Download an editable text brief or JSON file.

[Use the builder](https://snowrock.github.io/buyer-data-brief/) · [SnowRock buyer services](https://snowrock.com/buyers)

## How it works

Open the page, fill in what you know and choose **Preview & export**. Only a project name and task are required. Unanswered questions remain open. A fictional example is available after confirmation. It contains invented quantities and planning budgets, clearly labeled in the page and exports.

Answers stay in memory in your browser tab. The builder has no server, account, tracking, cookies, storage or network calls. Download a copy before refreshing or closing. It does not send a brief to SnowRock. Avoid entering confidential records or passwords.

The tool separates a license paid to a data owner, preparation and delivery costs, and SnowRock’s separately agreed service fee. It quotes no price and creates no order or agreement. Buyers and data owners agree licenses and direct delivery themselves.

## Run locally

Serve this directory with any static web server, or open index.html in a modern browser. There is no installation or build step. The complete tool is index.html, styles.css and app.js. Fonts come from the operating system; no external media is loaded.

## Accessibility and compatibility

Native controls have labels, errors identify the relevant fields, and keyboard users can open every section and dialog. Layouts and real text/JSON downloads were checked in Chrome at 320, 390, 768 and 1440 pixels. Other browsers and physical phone hardware have not been separately tested.
